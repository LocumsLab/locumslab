# Setting Up the Google Form (5 minutes) This replaces all the backend code from before — no Netlify functions, no Supabase schema changes, no verification emails. Google Forms auto-creates a linked Google Sheet for you, which is your submission log. The Excel tracker in this delivery is a *second*, more deliberate log you fill in by hand as you manually activate each candidate — use both if you like, or just the Sheet if that's enough. ## 1. Create the form Go to forms.google.com → Blank form. Name it **"LocumsLab Sponsored Access Request"**. Add these fields: | Field | Type | Required? | |---|---|---| | First name | Short answer | Yes | | Your email | Short answer (validate as email) | Yes | | Referring agency | Short answer | Yes — see prefill note below | | Have you already created a free LocumsLab account with this email? | Multiple choice (Yes / No) | Yes | | Is this your first locums assignment? | Multiple choice (Yes / No) | No | Keep it to this. Don't ask for phone number, salary, contract details, or which specific recruiter — those add friction at the exact moment you want a low-effort "yes," and none of it is needed to activate access. **Why the account question matters:** you can't grant Pro access to someone who doesn't have a LocumsLab account yet (there's no user record to attach it to). The landing page already tells candidates to sign up first — this question just tells you, at a glance, whether that actually happened before you go looking them up in Supabase. If they say "No," don't go searching for them — reply asking them to sign up at locumslab.com/app with the same email, then come back to grant access once they have. ### Prefilling the agency field Rather than making the candidate type the agency name (which invites typos and makes the form feel generic), prefill it per agency: 1. Fill out the form once yourself with the agency's name in the "Referring agency" field 2. Click the ⋮ menu → **Get pre-filled link** 3. Google gives you a URL with the agency name baked in and that field locked to read-only for the candidate 4. Use *that* URL (not the base form link) as the `href` in `sponsored-landing-page.html` for that specific agency If you're piloting with more than one agency, you'll have one prefilled link per agency, all pointing to the same form/Sheet — so your tracking stays in one place. Optional but nice: add a confirmation message under **Settings → Presentation → Confirmation message**: > "Thanks! You'll hear from LocumsLab directly within 1 business day with your access details." ## 2. Turn on the linked Sheet In the form editor, click the **Responses** tab → the green Sheets icon → **Create a new spreadsheet**. Every submission now lands there automatically, timestamped. ## 3. Get your share link Click **Send** (top right) → the link icon → check **Shorten URL** → copy it. This is what goes in `sponsored-landing-page.html` in place of `REPLACE_WITH_YOUR_FORM_LINK`, and it's also what you can hand agencies directly if you skip the landing page entirely for the very first pilot. ## 4.
